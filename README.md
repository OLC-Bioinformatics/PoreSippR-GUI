# PoreSippR-GUI
GUI for PoreSippR

## Installation

See [INSTALL.md](INSTALL.md) for prerequisites and setup instructions.

```bash
make setup
make run
```

Before starting an analysis, set the reference, POD5 location, barcode kit,
and output location for your run. See the application settings in [poresipprGUI_instructions.doc](poresipprGUI_instructions.doc).
