# PoreSippR-GUI
GUI for PoreSippR

See the [repository layout](docs/application/repository-layout.md) for the
application code, resources, examples, and tests.

## Installation

See [INSTALL.md](INSTALL.md) for prerequisites and setup instructions.

```bash
make setup
make run
```

Before starting an analysis, set the reference, POD5 location, barcode kit,
and output location for your run. See the application settings in
[poresipprGUI_instructions.doc](docs/application/poresipprGUI_instructions.doc).
